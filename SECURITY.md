# Security Policy & Vulnerability Reporting

## Supported Versions

| Version | Supported |
| :--- | :--- |
| v1.2.0 (Architecture Frozen) | Yes |
| v0.1.x (Phase 1 Infrastructure) | Yes |

## Reporting a Vulnerability

Siragugal Film Studio takes security very seriously. If you discover a security vulnerability, please do NOT open a public GitHub issue.

Instead, please send an encrypted email or report to:
`security@siragugalfilmstudio.com`

Include:
1. Description of the vulnerability and potential impact.
2. Step-by-step proof of concept to reproduce the issue.
3. Affected components or packages.

We will acknowledge receipt within 24 hours and issue a fix within 7 days for critical issues.
